# Open Decisions — KAIDO E-commerce

Ghi lại **mâu thuẫn, thiếu sót và mặc định đang áp dụng** trong quá trình khởi tạo nền tảng. Mỗi dòng có trạng thái:

- **Chưa chốt** — đang tạm áp dụng mặc định để không chặn phát triển; cần khách hàng/chủ SRS xác nhận.
- **Đã chốt** — đã thống nhất và triển khai; chỉ đổi khi có quyết định mới thay thế.

Bảng 1–19 chép từ yêu cầu khởi tạo (mục 5). Bảng 20–31 là các điểm phát hiện thêm trong quá trình dựng nền tảng. Không tự ý đổi mặc định trong code khi chưa cập nhật tài liệu này.

## 3. Cách cập nhật quyết định

1. Đổi trạng thái tại đây và ghi ngày + người quyết định trong commit/PR.
2. Nếu quyết định ảnh hưởng hợp đồng API: cập nhật `src/shared/api-endpoints.js`, chạy `npm run gen:routes`, cập nhật `docs/API_CATALOG.md`.
3. Nếu ảnh hưởng dữ liệu: cập nhật `database/schema.sql` / `seed.sql` và `docs/DATABASE.md`; viết migration mới thay vì sửa migration đã phát hành.
4. Nếu ảnh hưởng nghiệp vụ: cập nhật `src/shared/constants/business-rules.js` và seed `system_settings`.
5. Nếu ảnh hưởng giao diện: cập nhật `docs/DESIGN_SYSTEM.md` và token.
6. Chạy lại `npm run check:modules` và bộ kiểm tra ở `docs/CONTRIBUTING.md`.
