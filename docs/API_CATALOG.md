# API Catalog — KAIDO E-commerce

Tài liệu này được dựng từ **registry** [`src/shared/api-endpoints.js`](../src/shared/api-endpoints.js) — nguồn sự thật duy nhất cho backend và client. Khi hợp đồng đổi: cập nhật registry, chạy `npm run gen:routes`, rồi sửa lại catalog cho khớp (chưa có script sinh catalog tự động).

## 1. Quy ước chung

- Tiền tố: `/api/v1`. Health check `GET /api/v1/health` viết tay, không nằm trong registry.
- Envelope thành công: `{ "success": true, "data": ..., "meta": { "requestId": ... } }`.
- Envelope lỗi: `{ "success": false, "error": { "code", "message", "details"? }, "requestId": "..." }`.
- Route khung hiện trả `501 NOT_IMPLEMENTED` với `details.todo`; trạng thái từng endpoint ghi ở cột cuối.
- Quyền: **Công khai** (không cần token), **Công khai (đăng nhập tùy chọn)** (có token thì nhận diện thành viên), **Đăng nhập** (bắt buộc), **Vai trò** (bắt buộc đúng role; admin path còn phải thuộc nhóm vận hành).
- Tham số động thống nhất: `[orderRef]`, `[idOrSlug]`, `[ticketRef]`, `[itemId]`, `[id]`. `[id]` dùng cho thao tác admin theo ID nội bộ.
- `API-M06-05` là alias của `API-M05-05` (cùng method + path); registry giữ cả hai mã để bảo toàn SRS nhưng chỉ sinh một route.

## 2. Tổng hợp

- Tổng số bản ghi: **65** endpoint (trong đó **1** alias).
- Số endpoint chính: **64** → **60 file `route.js`** nghiệp vụ (4 cặp trùng path+method dùng chung file) + 1 file health = **61 file route**.
- Trạng thái hiện tại: 100% endpoint nghiệp vụ **chưa triển khai** (trả 501 đúng envelope).
